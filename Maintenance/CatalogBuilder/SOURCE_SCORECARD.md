# AutoSpec Source Scorecard

Use this scorecard to rank candidate vehicle-to-part data sources before integration.

## Scoring

Score each category 0-5.

- US Y/M/M/E fitment depth
- Maintenance category relevance
- Exact part-number quality
- Candidate-generation usefulness
- Independent-verification usefulness
- Access stability
- Bulk/download friendliness
- Rate-limit friendliness
- Commercial-use clarity
- Caching/redistribution clarity

Maximum raw score: 50.

## Decision bands

- 42-50: Tier 1 — integrate first
- 34-41: Tier 2 — strong secondary source
- 25-33: Tier 3 — verification/support only
- 0-24: Reject / defer
